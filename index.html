DuskJS Shell


    
    
Shell examples

    

    
Node REPL examples — run `node` first to enter the REPL, then click these. `.exit` returns to dsh.

    

    
node:crypto examples — run `node` first. Hashes/HMAC/AES/RSA/ECDSA/PBKDF2/WebCrypto. RSA/EC keypair gen takes 2-5s.

    

    
sqlite3 examples — sql.js on the host, TFS-persistent DB files.

    

    
python3 examples — Pyodide on the host, ~10MB download on first use.
